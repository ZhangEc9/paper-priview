## 配置中处理的问题

- Anaconda base 的原有 PyTorch 导入触发 OpenMP 重复加载；试配的 `.venv-cpu` 继承了 base，不作为最终环境。最终 `.venv` 由已有 Python 3.11 创建且不继承 base 包，导入和训练均通过。
- 默认 PyPI 下载 numpy 停滞，切换清华 PyPI 镜像完成依赖安装；CPU torch 来自官方 wheel 源。
- 未在公司电脑配置 Meta-World、CUDA、租卡或运行付费任务。
