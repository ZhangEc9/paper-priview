# 今天开始：CPU 单任务 SAC

更新：2026-11-02。当前设备：公司 Windows 电脑，无 GPU；回学校后再接 RTX 4060 Laptop。

研究偏好：持续强化学习中的知识组合、压缩与复用。11 月开题、次年 4 月答辩，论文可继续扩展。当前优先考察 CKA-RL，不把候选合并机制预先认定为创新。

## 1. 今天只完成什么

用 SAC 在 Pendulum-v1 上训练一个小策略，学会运行、评估、保存和重新加载。这个任务让倒立摆从自然下垂状态摆起并维持直立；动作是连续力矩。

今天使用 Stable-Baselines3 的 SAC；CKA-RL 在 Meta-World 上也使用 SAC，但今天的实现、网络、环境和超参都不是论文复现设置。Pendulum 单任务成功不能证明 CKA-RL 成功。

不需要先读完所有 RL 论文。先做第 2 节，再边看结果边读代码。

配置验证已实际通过：本机 10000 步训练约 108 秒，独立10局平均回报从随机策略的 -1223 提高到训练后的 -231，保存重载检查及 GIF 渲染成功。详见 `03_配置验证记录.md`；你的运行使用下面的新名字。

## 2. 复制命令即可开始

在 PowerShell 中执行以下命令。无需激活环境；明确指定解释器可以避免误用公司电脑上的其他 Python。

```powershell
Set-Location '.\CRL起步'
& '.\.venv\Scripts\python.exe' '.\single_task.py' train --name my_first_10k --steps 10000
```

每 1000 步打印一条开发评估。运行时可以继续看文档。重复运行需改名字，例如 `my_second_10k`，脚本会拒绝覆盖已有目录。

如果你只有几分钟，先执行短版本：

```powershell
& '.\.venv\Scripts\python.exe' '.\single_task.py' train --name my_first_2k --steps 2000 --eval-every 1000 --eval-episodes 5
```

2000 步主要检查流程；训练从第 500 步之后开始，短运行中回报尚未提高很正常。学习曲线向上更好，负回报从 -1200 到 -300 是进步。不要把 0 当作分类准确率的零分。

## 3. 看哪些结果

运行结束后查看 `runs/my_first_10k/`：

| 文件 | 看什么 |
|---|---|
| `summary.json` | 随机策略、未训练策略、训练后策略的平均回报；更新次数；耗时；保存后重载检查 |
| `learning_curve.png` | 不同训练步数的开发回报；是否有学习趋势 |
| `evaluations.csv` | 曲线原始数据，每次开发评估 3 局 |
| `train.monitor.csv` | 训练过程中每局回报，含随机探索和训练时的随机动作 |
| `environment.json` | 解释器、依赖版本、设备和参数 |
| `model.zip` | 策略、价值网络等模型状态；不含经验池，不能当成精确续训快照 |

最终比较用相同的 10 个新初始状态，开发评估用另一组固定初始状态。它是入门比较；一颗种子、一个任务不能说明研究结论。

若 10000 步仍没有明显提高，先把结果记录下来，不要一口气改多个超参。可以用新名称运行 20000 步，并查看参数是否有限、更新次数是否大于零。

## 4. 看策略动作

训练完成后，生成一段本地 GIF：

```powershell
& '.\.venv\Scripts\python.exe' '.\single_task.py' watch --model '.\runs\my_first_10k\model.zip'
```

生成 `runs/my_first_10k/policy.gif`。若想打开交互窗口观看：

```powershell
& '.\.venv\Scripts\python.exe' '.\single_task.py' watch --model '.\runs\my_first_10k\model.zip' --window
```

GIF/窗口只是演示，不代替定量评估。今天还不用录制机器人视频。

## 5. 你今天留下的学习记录

在 `我的第一次运行.md` 里用自己的话回答这五项即可：

1. 本次命令、运行名、随机种子和训练步数。
2. 随机策略、未训练 SAC 和训练后 SAC 的平均回报分别是多少？训练策略是否更好？
3. observation、action、reward 分别代表什么？Pendulum 的观察是 `[cos(theta), sin(theta), theta_dot]`，动作是力矩，奖励惩罚偏离直立、角速度和用力。
4. 为何训练回报与评估回报不同？训练有探索，评估采用确定动作；初始状态也可能不同。
5. 为什么目前还没有测量“遗忘”？因为只训练了一个任务，还没有学习第二个任务后重新评估第一个。

## 6. 环境说明

推荐使用当前目录的 `.venv`：独立 Python 3.11 环境和 CPU PyTorch，不修改公司已有 conda 环境。配置过程中发现 Anaconda base 存在 OpenMP 重复加载冲突，因此最终环境不继承 base 包，也不使用 `KMP_DUPLICATE_LIB_OK` 绕过。试配目录 `.venv-cpu` 不是最终入口，不使用它。

当前安装的直接依赖见 `requirements-cpu.txt`，完整版本见 `requirements-cpu-lock.txt`。迁移到另一台机器时只复制代码和文档，重新创建环境，不直接复制 `.venv`。

若需要在另一台有 Python 3.11 的 Windows 上重新配置：

```powershell
py -3.11 -m venv .venv
& '.\.venv\Scripts\python.exe' -m pip install torch==2.7.1 --index-url https://download.pytorch.org/whl/cpu
& '.\.venv\Scripts\python.exe' -m pip install -r requirements-cpu.txt
```

回学校的 GPU 环境单独配置，不把 CPU 版 torch 当作 CUDA 环境。
